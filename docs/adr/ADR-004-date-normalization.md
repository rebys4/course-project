# ADR-004: Нормализация дат (ISO 8601, запрет прошлых дат)

## Context
В Topics используются дедлайны. Нужна предсказуемость и корректная валидация.

## Decision
- Используем тип `date` (без TZ) в API.
- Валидация: `due_at >= today`.
- Сериализация — ISO 8601 по умолчанию FastAPI/Pydantic.

## Consequences
- Предсказуемая работа фильтров/сортировок.
- Меньше ошибок из-за TZ.
