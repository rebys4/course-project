# ADR-001: Error envelope + correlation_id (RFC7807-совместимость)

## Context
Нужен унифицированный формат ошибок и трассировка запросов. В P03 есть NFR-06: 100% критических ошибок должны логироваться с trace_id. Сейчас у нас единый конверт ошибок, но нет correlation_id и RFC7807-полей.

## Decision
- Для каждого запроса генерируем/принимаем `X-Request-Id` и возвращаем его в заголовке ответа и в теле ошибок как `correlation_id`.
- Обогащаем тело ошибок полями RFC7807 (`type`, `title`, `status`, `detail`, `instance`) при сохранении текущего поля `error`.
- Не раскрываем внутренние детали исключений клиенту.

## Consequences
- Упрощается отладка и трассировка инцидентов по `X-Request-Id`.
- Клиенты получают стабильный формат ошибок, без утечки чувствительных деталей.
